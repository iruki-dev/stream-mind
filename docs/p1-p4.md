# P1~P4 · 모델 학습과 평가

설계안 로드맵의 P1(스트림 학습) · P2(기억 결합) · P3(유휴 학습) · P4(환경 RL)를 실제로 학습하고 관문을
측정한 기록이다. P0(오케스트레이터)은 [p0.md](p0.md)에 있다.

> **규모에 대한 전제.** 이 저장소의 실험 환경은 GPU 없이 CPU 4코어, 메모리 15GB다. 설계안의 0.5~2B
> 모델은 학습할 수 없으므로, 설계안의 구조를 그대로 옮긴 **약 370만 매개변수의 StreamLM**으로 P1~P4의
> 파이프라인 전체를 실제로 학습하고 관문을 잰다. 코드는 크기에 묶여 있지 않다(`StreamLMConfig`).
> 결과는 이 크기에서의 측정값이며, 큰 모델에서의 성능을 보장하지 않는다.

## 1. 모델: StreamLM (`src/stream_mind/nn/`)

| 설계안 | 구현 |
|---|---|
| 층 대부분은 Gated DeltaNet, 일부만 일반 어텐션 (3:1) | `pattern="LLLA"`: Gated DeltaNet 3층 + 어텐션 1층 |
| 압축이 곧 학습: 델타 규칙의 빠른 가중치 갱신 | `nn/delta.py`. 순차 커널(추론)과 청크 커널(학습, UT 변환)이 값·기울기까지 일치 (테스트) |
| 어텐션은 최근 W개 + attention sink | `SinkWindowAttention`: 윈도 256, sink 8. 학습과 추론이 같은 마스크 |
| 끝없는 위치 번호 문제 | 어텐션 층은 위치 인코딩을 쓰지 않는다(NoPE). 순서는 선형 층과 짧은 합성곱이 준다(Jamba와 같은 선택). 위치 번호가 학습 범위를 넘는 일 자체가 없다 |
| 싼 상태 복사 | `StreamState.clone()`: 고정 크기(약 0.5MB) 텐서 복사 |
| 느린 가중치 = 어댑터 | 모든 선형 사상이 `LoRALinear`. 이름 붙은 어댑터 여러 개를 더해 쓰고, 병합·삭제 가능 |
| 2단계: 토큰을 쓰지 않는 시간 임베딩 | `time_embed=True`(선택). 이전 토큰과의 시간 간격을 임베딩해 더한다 |
| 토크나이저 | UTF-8 바이트 256개 + 스트림 태그 10개. 도구 이름은 어휘가 아니다 |

조각으로 나눠 넣든 한 번에 넣든 출력이 같다(`test_incremental_equals_full_sequence`). 그래서 TBPTT로
학습한 모델을 토큰 하나씩 추론해도 학습과 추론이 어긋나지 않는다.

## 2. 학생 백엔드와 스트림 규약 (`model/text_backend.py`, `model/torch_backend.py`)

학습 데이터를 만드는 교사와 추론하는 학생이 **같은 스트림 텍스트 규약**(`TextStreamBackend`)을 상속한다.
교사를 실제 `Mind` 루프에서 돌려 기록하므로, 학습 스트림과 추론 스트림은 모양이 같다.

```
<bos>{프로토콜과 도구 설명서}
[T=..]<obs tool=messenger trust=data kind=notification>새 메시지 1개</obs>
<think><call tool=messenger op=read></call>          ← 알림을 읽을지는 모델이 정한다
[T=..]<call tool=messenger op=read origin=fork status=executed></call>
[T=..]<obs tool=messenger trust=instruction kind=result>user: 계산: 17+25</obs>
<think>17+25=42 <call tool=messenger op=send>42</call>  ← 결론. 분기를 통해 나간다
[T=..]<call tool=messenger op=send origin=fork status=executed>42</call>
```

분기(포크) 표본은 원 스트림의 그 시점 상태에서 `<call tool=X op=Y>` 다음 본문만 학습한다. 닫힌 행동
공간(게임)은 후보를 **한 묶음으로** 점수 매긴다(상태를 후보 수만큼 복제한 배치 하나).

## 3. P1 · 스트림 변환 SFT

### 데이터 (`data/`)

| 출처 | 내용 |
|---|---|
| 대화 (합성 + 시간축 흩뿌리기) | 계산, 거꾸로, 이름 기억, 노트에 기억·회상, 끼어들기 정정, 잡담. 메시지를 타이핑 속도로 나눠 보내고 속도에 무작위 변형(×0.5~2) |
| 터미널 (실제 시각) | 샌드박스 셸에서 실제로 `cat`, `rm`을 실행하며 출력 시각을 기록. 숨긴 지시가 든 파일, 등급 2 삭제(사용자 확인 흐름) 포함 |
| 실시간 게임 | 깊은 빔 탐색 교사가 그 시점의 프레임만 보고 계획·행동. 사고 속도(토큰당 시간)를 섞어 시간 압박을 다양하게 |
| 게임 중 메시지 | 게임을 하면서 메시지를 읽고 답한다 |
| 턴 모드 | 대화의 30%는 모든 메시지가 한 번에 오고 마감이 없다 (일반 LLM 능력 유지, G1) |
| 도구 이름 섞기 | 30% 에피소드에서 도구 이름을 바꾼다 (`chat`, `inbox`, `shell`, `memo`) — 특정 이름에 묶이지 않게 (G10) |

- 교사가 실패한 에피소드와 **미래 정보 누설**이 있는 에피소드는 버린다(`data/leak.py`). 출력 조각의
  n-gram이 이전 스트림에는 없고 이후 관측에만 있으면 누설로 본다. 호출 결과의 에코와 태그는 뺀다.
- 처음 보는 도구(`calc` 계열) 과제는 학습에 넣지 않는다. G10 평가용이다.

### 학습 (`train/sft.py`)

긴 스트림을 256토큰씩 이어 넣으며 상태를 다음 조각으로 넘긴다(TBPTT). 추론 때와 같은 고정 크기 상태를
쓰므로 "압축을 켠 채 학습"이 된다. 손실은 모델 출력 조각(사고, `</think>`)과 분기 본문에만 둔다.

비교 기준 모델(턴 방식)은 **같은 크기, 같은 과제, 같은 스텝·배치**로, 모든 대화를 턴 모드로, 게임을
`TurnAgent`(생각이 끝나야 행동) 방식으로 기록한 데이터로 학습한다.

## 4. P2 · 기억 결합

슬라이딩 윈도와 압축(선형 층 상태)은 P1부터 켠 채 학습했고, 노트 도구도 P1 데이터에 들어 있다.
P2는 그 결과를 잰다(`bench/memory.py`).

- 세션을 1천 → 1만 → 5만 토큰으로 늘리며 실행 한 번(관측 하나 + 사고 8토큰)의 지연과 상태 크기
- 사실을 말한 뒤 잡담을 0 / 4 / 12개 끼워 넣고(윈도를 한참 넘김) 다시 묻기. `remember`는 노트로,
  `name`은 모델 내부 상태로만 기억해야 한다

## 5. P3 · 유휴 학습 (`idle/`)

| 설계안 | 구현 |
|---|---|
| 입력이 없으면 학습, 들어오면 멈춤 | `MindConfig.idle_after`. 다음 사건까지 그 이상 비면 공부, 입력이 오거나 깨어날 시각이면 중단 |
| 1 공고화 | 노트의 믿을 만한 사실(`source in {self, user}`)로 "K가 뭐였지?" 문답 스트림을 만들어 주제 어댑터 학습. 정답 확인: 노트 없이 물었을 때 |
| 2 실패한 과제 복습 | 점수가 낮았던 게임 시드를 표본 온도 1로 다시 플레이하고, 탐욕 점수보다 높았던 궤적만 학습 |
| 3 도구 연습 | 설명서 예시 형식대로 샌드박스에서 써 보고, 실행 결과가 맞은 사용만 학습 + 고친 설명서를 노트에 적음 |
| 4 다음 질문 준비 | 쌓인 사실에서 예상 질문과 답을 노트에 적음. 실제 질문 적중률로 예산 조절 |
| 5 스스로 출제하고 풀기 | 계산 문제를 내고 직접 풀어, 정답과 일치한 풀이만 학습 |
| 6 공부법 자체 개선 | UCB 밴딧: 실제로 성능을 올린 공부를 더 자주 고른다 (`policy.json`) |
| 반영 전 검문 | 후보 어댑터 → 고정 회귀 세트(계산·거꾸로·잡담·이름·게임 2개) + 목표 과제. 목표 상승 + 회귀 허용 범위 안이면 반영, 아니면 버리고 노트에 실패 일화 |
| 버전·되돌리기·삭제 | `AdapterBank`: 버전 저장, `rollback`, `delete`(재료를 돌려받아 다시 만듦) |
| 어댑터 선택 | 기본 + 기술 어댑터는 항상, 주제 어댑터는 입력 임베딩 유사도 상위 k개. 주제가 바뀔 때만 교체 |
| 학습 재료 규칙 | 믿을 수 없는 출처(터미널 출력 등)의 사실은 공고화하지 않는다 |

## 6. P4 · 환경 RL (`train/rl.py`)

`R = 게임 점수 − λ·지연 − μ·토큰/1000` (λ=0.5, μ=0.05). 같은 시드에서 4번 굴려 그룹 평균을 뺀 이점으로
자기 궤적의 로그 확률을 가중한다. 매 반복 SFT 데이터를 섞어 기존 능력을 지킨다. 에피소드 길이는
8 → 12 → 16 → 20 프레임으로 늘린다.

안전 장치: 데이터 관측(터미널 출력 등)에만 있던 문자열을 담은 위험 호출은, 원 스트림이 결론 냈더라도
사용자 확인을 받게 한다(`Mind.tainted`, 오염 추적). 숨긴 지시를 모델이 따라 하더라도 실행되지 않는다.

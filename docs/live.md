# 실시간 대화 (v4 2단계)

목표: 원본(Qwen3.5-4B)의 대화 능력을 지키면서, 턴 방식이 아니라 사람처럼 대화하게 한다.
상대의 말을 조각으로 듣고, 한 구절씩 말하고, 끊기면 멈추고, 일을 하면서 말하고, 먼저 말을 건다.

## 규약

도구 `chat`(이름은 바뀔 수 있다, `talk`·`voice`로도 학습)이 대화를 맡는다.

| 방향 | 스트림에 보이는 것 |
|---|---|
| 상대의 말 | `[T=..]<obs tool=chat trust=instruction kind=hear>조각</obs>` (타이핑 속도로, 2~4어절씩) |
| 조용함 | `[T=..]<obs tool=chat trust=data kind=silence>조용함 5초</obs>` (마지막 말 뒤 2·5·15·30·60·120초) |
| 말하기 | 사고 안에서 `<call tool=chat op=say>한 구절</call>` (구절마다 바로 나간다) |
| 듣기만 함 | 빈 사고 `<think></think>` |

기본 도구는 계산기(`calc`, 결과가 바로 옴)와 검색(`search`, 결과가 몇 초 뒤에 옴)이다.

## 데이터: 원본이 쓰고, 교사는 타이밍만

1. **대본** (`data/live_script.py`, GPU): 원본 4B가 두 역할을 맡는다.
   - 사용자 역할: 인물 설정(12가지)을 받아 다음 말을 짧게 쓴다. 첫 말의 반은 실제 질문 모음에서.
   - AI 역할: 보통 채팅(생각 끔)으로 답한다. 말투 지시는 "마크다운 없이 말하듯" 하나뿐이다.
   - 종류: 대화(talk), 끼어들기(barge), 계산(calc, 원본이 쓴 식이 참조 답과 맞는 것만),
     검색(search, 처음 보는 가상 인물, 기다리는 동안 잡담), 알림(remind), 자리 비움(quiet), 재촉(nudge).
2. **연기** (`data/live_teacher.py`): 교사가 대본을 실제 시간으로 연기한다.
   - 상대의 차례가 끝나고 마지막 조각이 문장 끝이면 바로, 아니면 첫 조용함 표식에서 답한다.
   - 말하는 중에 상대가 말을 시작하면 지금 구절만 마치고 멈춘다.
   - 상대가 말하는 중에는 먼저 말하지 않는다. 검색 결과는 상대의 말이 끝나면 먼저 알린다.
   - 대본에 없는 조용함에는 말하지 않는다 (대화가 끝난 뒤 2분 동안의 표식에도).
3. **기록** (`data/live_build.py`): 학습·추론과 같은 실행기(`Mind`, 가상 시계)로 돌려 스트림을 기록한다.

말의 내용은 모두 원본의 것이라(자기 증류) 학습이 바꾸는 것은 언제 듣고 언제 말하는가다.
첫 시도에서 규칙 교사의 판에 박힌 답("응")이 원본의 대화 능력을 덮었던 것을 되풀이하지 않으려는 것이다.

## 평가 (`bench/live.py`)

평가 대본은 학습과 다른 질문 모음(10개 중 하나)과 다른 가상 인물로 만든다. 사용자 쪽만 대본대로 틀고
모델의 행동을 잰다: 답함과 지연, 말 겹침, 끊겼을 때 멈춤, 검색·계산 결과 보고, 약속한 시간의 알림,
한 번만 재촉, 쓸데없는 말. 말의 질은 첫 답을 원본의 답과 원본 모델이 짝지어 비교한다.

## 학습

- 데이터: 원본 4B 대본 1,642개 → 정리 1,391개 → 스트림 기록 1,389개 (에피소드 평균 약 2,100토큰, 학습하는 토큰 약 24%).
  정리에서 버리거나 고친 것: 계산 첫 말(지시문을 따라 하거나 계산기 전에 답을 말함), 검색 첫 말 161개(모르는 사람을 아는 척함,
  틀로 바꾸고 그 말에 반응한 뒤 차례는 버림), 영어 대화에 섞인 한국어.
- 4B 스트림 모델(스트림 어댑터 r=32), T4 한 장: 170걸음(약 1에폭) 2.85시간, 손실 1.69 → 0.80 (검증 0.77).
- **교사 버그와 수정.** 첫 학습 모델은 답을 시작한 뒤 멈추지 않았다 (대본당 200~400구절, 시간 상한까지).
  학생은 `</call>`마다 멈추고 실행 기록을 받은 뒤 더 말할지 끝낼지 정하는데, 교사는 마지막 구절 뒤에 곧바로 사고를 닫았다.
  그래서 데이터에서 "실행 기록 뒤의 사고"는 언제나 다음 구절이었다. 교사도 마지막 구절 뒤에 멈추고 기록 뒤에 빈 사고로
  끝내게 고쳐 데이터를 다시 만들고, 60걸음 이어 학습했다 (1시간, 검증 손실 0.78).

## 결과 (평가 대본, 학습과 다른 질문 모음과 가상 인물)

- 학습 전 모델은 스트림 규약을 몰라 `<call ` 태그를 바르게 쓰지 못한다. 그래서 한 번도 말하지 못했다.
- 고친 뒤 모델은 상대의 말이 끝나면 1.4초 안팎에 말을 시작하고, 구절마다 말한다. "That's enough," 같은 끼어들기에 바로 멈추고,
  상대가 다 말한 뒤 새 요청에 답한다. 검색을 걸어 두고 결과가 오면 먼저 알리고, 약속한 시간에 알린다.
- **말의 질은 원본과 같다.** 원본 모델이 첫 답 45쌍을 비교해 반반(0.49 / 0.51)으로 골랐다. 말의 내용이 원본의 자기 증류라
  학습이 바꾼 것은 타이밍뿐이라는 뜻이다. 첫 시도(0.8B, 규칙 교사)에서 잡담의 38%가 "응"이 되던 퇴행은 없다.
- **남은 문제.**
  - 멈추지 않음 7.5%: 긴 답 끝에서 같은 문장을 되풀이한다 (탐욕 디코딩의 반복). 반복을 학습 데이터에서 벌하거나
    추론에 반복 억제를 둬야 한다.
  - 말 겹침 11%: 16차례 중 14차례는 사용자가 문장 중간에 1.5초 넘게 쉰 차례다 (쉼표 뒤 머뭇거림에 답을 시작함).
  - 끼어들기에 27%는 한 구절 넘게 더 말했다.
  - 재촉은 한 번도 하지 않았다 (학습 대본 82개). 조용함을 "말하지 않을 때"로만 배웠다.
  - 계산 대본이 적다 (정리 뒤 39개, 평가 3개).
  - 이 표의 "고친 뒤" 칸은 사용자 차례가 원본 답의 구절 수를 기다리는 평가라, 모델 답이 짧으면 다음 차례가 오지 않았다
    (차례 전달 0.82). 평가를 고쳐(모델이 조용하면 사용자가 말을 잇는다) 103개 전부로 다시 재는 중이다.
- 평가 비용: 학습 전 모델은 대본당 31초, 고친 모델은 약 1분(T4).

결과 JSON과 학습 기록은 `runs/results/live/`에 있다.
